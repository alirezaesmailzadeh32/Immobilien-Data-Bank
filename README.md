# Immobilien Datenbank Projekt

## Projektübersicht

Im Rahmen dieses Projekts wurde eine relationale Datenbank für ein Immobilienunternehmen entworfen und implementiert. Ziel war es, eine skalierbare, strukturierte und datenintegritätsgesicherte Datenbanklösung für typische Geschäftsprozesse in der Immobilienbranche zu entwickeln.

## Projektinhalte

- Entwurf und Implementierung einer relationalen Datenbank mit über 10 normalisierten Tabellen  
- Erstellung eines relationalen Schemas basierend auf einem detaillierten ER-Modell  
- Modellierung von 1:n- und m:n-Beziehungen zur Abbildung realer Geschäftsprozesse  
- Entwicklung von SQL-Business-Logik mittels:
  - Stored Procedures  
  - Triggern  
  - Benutzerdefinierten Funktionen (skalare und table-valued Funktionen)  
- Sicherstellung der Datenintegrität durch:
  - Primary und Foreign Keys  
  - Constraints (NOT NULL, UNIQUE, CHECK)  
  - Index-Strukturen zur Performance-Optimierung  

## Technische Schwerpunkte

SQL, Relationale Datenbanken, Datenmodellierung (ER-Modell), Normalisierung, Datenintegrität, Stored Procedures, Trigger, User Defined Functions (UDFs)

## Ziel des Projekts

Das Ziel des Projekts war es, eine robuste Datenbankarchitektur zu entwickeln, die reale Geschäftsprozesse eines Immobilienunternehmens effizient unterstützt und gleichzeitig hohe Datenqualität und Konsistenz gewährleistet.
